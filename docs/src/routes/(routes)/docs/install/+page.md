<Translate text="You need <a target=_blank' href='https://nodejs.org/en/download/'>Node.js</a> and <a target='_blank' href='https://vite.dev/'>Vite</a> installed. No Tailwind CSS needed — daisyUI classes are generated by UnoCSS." />

### 1. Install the packages

```sh:Terminal
bun add unocss @unocss/vite @unocss/preset-typography unocss-preset-daisy
```

### 2. Add the UnoCSS Vite plugin

```js:vite.config.js
import UnoCSS from "@unocss/vite"

export default {
  plugins: [UnoCSS()],
}
```

### 3. Create a UnoCSS config file

Create a `uno.config.ts` file in the root of your project and add the following code.
`presetDaisy()` replaces `@plugin "daisyui"` and `presetTypography()` replaces
`@plugin "@tailwindcss/typography"`.

```js:uno.config.ts
import { presetUno } from "unocss"
import presetTypography from "@unocss/preset-typography"
import { presetDaisy } from "unocss-preset-daisy"

export default {
  // REQUIRED: colon-only separators. daisyUI class names such as `hover-3d`,
  // `file-input-*` and `link-*` collide with Uno's dash-form variants
  // (`hover-*`, `file-*`, `link-*`). Colon-form variants (`sm:`, `hover:`)
  // keep working.
  separators: [":"],
  presets: [
    presetUno(),
    // `themes: false` enables all 35 themes (same as `themes: all` upstream)
    presetDaisy({ themes: false }),
    presetTypography(),
  ],
}
```

### 4. Import the CSS entries

Import the generated utilities once (replaces `@import "tailwindcss"`), plus the
35-theme stylesheet (replaces the `@plugin "daisyui"` theme output):

```js:+layout.svelte
import "uno.css"
import "unocss-preset-daisy/themes"
```

Now you can use daisyUI class names!

```html:example
<button class="btn btn-primary">Button</button>
```
